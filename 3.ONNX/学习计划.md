# 🎯 学习目标

* 掌握 **ONNX 的模型结构、文件格式**，理解它如何作为中间表示(IR)。
* 熟悉 **ONNX Runtime** 的使用，能在 C++ 中加载并运行模型。
* 学会 **从 PyTorch/TensorFlow 导出模型到 ONNX**，并验证推理正确性。
* 理解 **ONNX 算子 (Operator)** 与推理图 (Graph)。
* 具备 **模型优化、量化、部署** 的能力。

# 📚 学习计划

## 阶段 1：ONNX 基础认知 (1 周)

\*\*目标：\*\*理解 ONNX 是什么，能看懂基本的 `.onnx` 模型结构

* 阅读 [ONNX 官方文档](https://onnx.ai/)
* 学习内容：
  1. 什么是 ONNX？（中间表示，跨框架模型交换标准）
  2. ONNX 模型结构：Graph、Node、Tensor、Operator
  3. 熟悉 ONNX 的常见算子 (如 MatMul、Relu、Softmax)
* 实践任务：
  * 安装 `onnx` Python 包
  * 用 PyTorch 导出一个简单的 MLP 到 ONNX (`torch.onnx.export`)
  * 用 `onnxruntime` Python 版运行并验证推理结果
  * 使用 `Netron` 工具可视化模型结构

## 阶段 2：ONNX Runtime 使用 (2 周)

\*\*目标：\*\*掌握 ONNX Runtime 基本使用，在 Python 和 C++ 中跑通推理

* 学习内容：
  1. ONNX Runtime 基础 API (Python)
  2. ONNX Runtime C++ API，如何加载模型、输入数据、获取输出
  3. C++ 中如何配合 OpenCV (处理输入图像 → 转成 tensor → 推理 → 后处理)
* 实践任务：
  * Python: 跑通 ResNet/MobileNet 的推理
  * C++: 用 ONNX Runtime 加载 MNIST/MobileNet 模型进行推理
  * 对比 Python 和 C++ 输出，确认一致性

## 阶段 3：ONNX 模型生成与验证 (2 周)

\*\*目标：\*\*掌握如何将不同框架的模型转为 ONNX，并验证正确性

* 学习内容：
  1. PyTorch → ONNX (`torch.onnx.export`)
  2. TensorFlow → ONNX (`tf2onnx`)
  3. 验证 ONNX 模型正确性的方法 (ONNX Checker, Runtime 验证)
* 实践任务：
  * 把自己写的 PyTorch MLP 转换为 ONNX
  * 用 ONNX Runtime C++ 跑自己导出的 MLP
  * 导出一个 CNN (如 ResNet18)，在 ONNX Runtime 运行

## 阶段 4：ONNX 高级与优化 (2-3 周)

\*\*目标：\*\*学习优化 ONNX 模型以适应实际推理部署场景

* 学习内容：
  1. ONNX Graph 优化 (`onnxoptimizer`, `onnxruntime-tools`)
  2. 模型量化 (Dynamic Quantization, QAT, Post-training Quantization)
  3. ONNX Runtime 的执行提供者 (CPU, CUDA, TensorRT, OpenVINO)
* 实践任务：
  * 对 ResNet 模型做推理性能对比（未优化 vs. 优化后）
  * 使用量化工具将模型压缩，并验证精度影响
  * 在 CPU/GPU 上跑 benchmark，分析性能瓶颈

## 阶段 5：综合项目 (2-3 周)

\*\*目标：\*\*做一个完整的小型推理部署项目

* 项目建议：
  * 任务：图像分类 / 目标检测 / OCR 识别
  * 流程：
    1. 用 PyTorch 训练 → 导出 ONNX
    2. 在 C++ 中用 ONNX Runtime 部署
    3. 输入通过 OpenCV 处理 → ONNX Runtime 推理 → 输出可视化
    4. 尝试优化（量化、图优化、GPU/TensorRT 加速）
* 项目成果：一个可以在 PC 上实时跑的推理 Demo

# 🔧 学习工具

* **模型可视化**: [Netron](https://netron.app/)
* **ONNX Runtime C++ API 文档**: [https://onnxruntime.ai/](https://onnxruntime.ai/)
* **模型优化工具**: onnxoptimizer, onnxruntime-tools
* **测试数据**: MNIST / CIFAR / ImageNet 预训练模型

# 📈 学习路径总结

1. **理解 ONNX 模型结构** → 能看懂 `.onnx` 文件
2. **跑通 ONNX Runtime** → Python 快速实验，C++ 实现部署
3. **学会导出与验证** → PyTorch/TensorFlow 转 ONNX
4. **学会优化与量化** → 提升推理性能
5. **综合项目实战** → 完成从训练到 C++ 部署的完整流程
