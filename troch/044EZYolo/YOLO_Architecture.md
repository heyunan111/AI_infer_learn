# YOLO 网络架构详解

## 整体架构

YOLO 网络由三部分组成：
1. **Backbone (MiniCSPDarknet)** - 特征提取
2. **Neck (FPN + PAN)** - 多尺度特征融合
3. **Head** - 检测头

---

## 1. Backbone: MiniCSPDarknet

### 数据流图

```
输入图像 (3, 640, 640)
    ↓
┌─────────────────────────────────────┐
│ Stage1: Conv(3→32, k=6, s=2)        │
│         Conv(32→64, k=3, s=2)       │
│         C3(64→64, n=1)              │
└─────────────────────────────────────┘
    ↓ (64, 160, 160)
┌─────────────────────────────────────┐
│ Stage2: Conv(64→128, k=3, s=2)      │
│         C3(128→128, n=2)            │
└─────────────────────────────────────┘
    ↓ P3 (128, 80, 80) ──────────────────┐
┌─────────────────────────────────────┐  │
│ Stage3: Conv(128→256, k=3, s=2)     │  │
│         C3(256→256, n=3)            │  │
└─────────────────────────────────────┘  │
    ↓ P4 (256, 40, 40) ──────────────┐   │
┌─────────────────────────────────────┐  │   │
│ Stage4: Conv(256→512, k=3, s=2)     │  │   │
│         C3(512→512, n=1)            │  │   │
└─────────────────────────────────────┘  │   │
    ↓ P5 (512, 20, 20) ──────────┐      │   │
┌─────────────────────────────────┐│      │   │
│ Stage5: Conv(512→1024, k=3, s=2)││      │   │
│         C3(1024→1024, n=1)      ││      │   │
└─────────────────────────────────┘│      │   │
    ↓ P6 (1024, 10, 10) [不使用]  │      │   │
                                   │      │   │
                    输出到 Neck ───┴──────┴───┘
                                   P5    P4   P3
```

### 特征层级说明

| 层级 | 尺寸  | 通道数 | 感受野 | 用途         |
| ---- | ----- | ------ | ------ | ------------ |
| P3   | 80×80 | 128    | 小     | 检测小物体   |
| P4   | 40×40 | 256    | 中     | 检测中等物体 |
| P5   | 20×20 | 512    | 大     | 检测大物体   |

## 2. Neck: FPN + PAN

### 完整数据流图

```
来自 Backbone:
P3 (128, 80, 80)    P4 (256, 40, 40)    P5 (512, 20, 20)
     │                   │                   │
     │                   │                   │
     │                   │              ┌────▼────┐
     │                   │              │ reduce  │ 1×1 Conv(512→256)
     │                   │              │  p5     │
     │                   │              └────┬────┘
     │                   │                   │ p5_re (256, 20, 20)
     │                   │                   │
     │                   │              ┌────▼────┐
     │                   │              │Upsample │ 2× (256, 40, 40)
     │                   │              └────┬────┘
     │              ┌────▼────┐              │
     │              │   p4    │◄─────────────┘
     │              └────┬────┘ Concat (256+256, 40, 40)
     │                   │
     │              ┌────▼────┐
     │              │ fuse_p4 │ 3×3 Conv(512→256)
     │              └────┬────┘
     │                   │ p4_td (256, 40, 40)
     │                   │
     │              ┌────▼────┐
     │              │ reduce  │ 1×1 Conv(256→128)
     │              │  p4     │
     │              └────┬────┘
     │                   │ p4_re (128, 40, 40)
     │                   │
     │              ┌────▼────┐
     │              │Upsample │ 2× (128, 80, 80)
     │              └────┬────┘
┌────▼────┐              │
│   p3    │◄─────────────┘
└────┬────┘ Concat (128+128, 80, 80)
     │
┌────▼────┐
│ fuse_p3 │ 3×3 Conv(256→128)
└────┬────┘
     │ p3_td (128, 80, 80) ◄─── FPN 输出 1
     │
     │
═══════════════════════════════════════════════════════
     │              FPN (Top-Down) 结束
     │              PAN (Bottom-Up) 开始
═══════════════════════════════════════════════════════
     │
     │ p3_td (128, 80, 80)
     │
┌────▼────┐
│ down_p3 │ 3×3 Conv(128→256, s=2)
└────┬────┘
     │ p3_down (256, 40, 40)
     │                   │
     │              ┌────▼────┐
     └─────────────►│  p4_td  │ (256, 40, 40)
                    └────┬────┘ Concat (256+256, 40, 40)
                         │
                    ┌────▼────┐
                    │fuse_p4_2│ 3×3 Conv(512→256)
                    └────┬────┘
                         │ p4_out (256, 40, 40) ◄─── PAN 输出 2
                         │
                    ┌────▼────┐
                    │ down_p4 │ 3×3 Conv(256→512, s=2)
                    └────┬────┘
                         │ p4_down (512, 20, 20)
                         │                   │
                         │              ┌────▼────┐
                         └─────────────►│   p5    │ (512, 20, 20)
                                        └────┬────┘ Concat (512+512, 20, 20)
                                             │
                                        ┌────▼────┐
                                        │fuse_p5_2│ 3×3 Conv(1024→512)
                                        └────┬────┘
                                             │
                                             │ p5_out (512, 20, 20) ◄─── PAN 输出 3
                                             │
                                             ▼
                                    输出到 Detection Head
```

### FPN (Feature Pyramid Network) - 自顶向下

**目的**: 将高层语义信息传递到低层，增强小物体检测能力

```
P5 (512, 20×20)
  │
  ├─► reduce_p5: 1×1 Conv(512→256)
  │
  ├─► Upsample 2× → (256, 40×40)
  │
  └─► Concat with P4 → (512, 40×40)
      │
      └─► fuse_p4: 3×3 Conv(512→256) → p4_td
          │
          ├─► reduce_p4: 1×1 Conv(256→128)
          │
          ├─► Upsample 2× → (128, 80×80)
          │
          └─► Concat with P3 → (256, 80×80)
              │
              └─► fuse_p3: 3×3 Conv(256→128) → p3_td
```

**关键操作**:
- `reduce`: 降低通道数，减少计算量
- `Upsample`: 上采样，匹配空间尺寸
- `Concat`: 特征拼接，融合不同层级信息
- `fuse`: 3×3卷积融合特征

### PAN (Path Aggregation Network) - 自底向上

**目的**: 将低层定位信息传递到高层，增强大物体检测能力

```
p3_td (128, 80×80)
  │
  ├─► down_p3: 3×3 Conv(128→256, s=2) → (256, 40×40)
  │
  └─► Concat with p4_td → (512, 40×40)
      │
      └─► fuse_p4_2: 3×3 Conv(512→256) → p4_out
          │
          ├─► down_p4: 3×3 Conv(256→512, s=2) → (512, 20×20)
          │
          └─► Concat with p5 → (1024, 20×20)
              │
              └─► fuse_p5_2: 3×3 Conv(1024→512) → p5_out
```

**关键操作**:
- `down`: stride=2 的卷积，降低空间分辨率
- `Concat`: 与 FPN 输出或原始特征拼接
- `fuse`: 3×3卷积融合特征

---

## 3. 最终输出

经过 FPN + PAN 后，得到三个增强的特征图：

| 输出   | 尺寸  | 通道数 | 来源 | 特点                      |
| ------ | ----- | ------ | ---- | ------------------------- |
| p3_td  | 80×80 | 128    | FPN  | 融合了高层语义 + 低层细节 |
| p4_out | 40×40 | 256    | PAN  | 融合了上下文信息          |
| p5_out | 20×20 | 512    | PAN  | 融合了底层定位信息        |

这三个特征图会送入检测头进行最终的目标检测。

---

## 4. 为什么需要 FPN + PAN？

### 单独使用 Backbone 的问题

```
P3 (小尺度) → 细节丰富，但语义弱 → 难以识别物体类别
P5 (大尺度) → 语义强，但细节少 → 难以精确定位小物体
```

### FPN 的作用

```
P5 的语义信息 ──上采样──► 融合到 P4
P4 的语义信息 ──上采样──► 融合到 P3

结果: P3 获得了高层语义，能更好地识别小物体
```

### PAN 的作用

```
P3 的定位信息 ──下采样──► 融合到 P4
P4 的定位信息 ──下采样──► 融合到 P5

结果: P5 获得了底层细节，能更精确地定位大物体
```

### 双向融合的优势

```
         FPN (↓)
P3 ◄──────────── P5
 │               │
 │   PAN (↑)     │
 └──────────────►│

P3: 小物体检测 (细节 + 语义)
P4: 中物体检测 (平衡)
P5: 大物体检测 (语义 + 定位)
```

## 5. 通道数变化总结

```
Backbone 输出:
  P3: 128 channels
  P4: 256 channels
  P5: 512 channels

FPN 阶段:
  P5 → reduce → 256 → upsample → concat with P4(256) → 512 → fuse → 256 (p4_td)
  P4_td → reduce → 128 → upsample → concat with P3(128) → 256 → fuse → 128 (p3_td)

PAN 阶段:
  P3_td(128) → down → 256 → concat with p4_td(256) → 512 → fuse → 256 (p4_out)
  P4_out(256) → down → 512 → concat with p5(512) → 1024 → fuse → 512 (p5_out)

最终输出:
  p3_td:  128 channels, 80×80
  p4_out: 256 channels, 40×40
  p5_out: 512 channels, 20×20
```

## 6. 代码对应关系

| 操作    | 代码                          | 输入           | 输出          |
| ------- | ----------------------------- | -------------- | ------------- |
| 降通道  | `reduce_p5(p5)`               | (512, 20, 20)  | (256, 20, 20) |
| 上采样  | `up(p5_re)`                   | (256, 20, 20)  | (256, 40, 40) |
| FPN融合 | `fuse_p4(cat[p4, up])`        | (512, 40, 40)  | (256, 40, 40) |
| 降通道  | `reduce_p4(p4_td)`            | (256, 40, 40)  | (128, 40, 40) |
| 上采样  | `up(p4_re)`                   | (128, 40, 40)  | (128, 80, 80) |
| FPN融合 | `fuse_p3(cat[p3, up])`        | (256, 80, 80)  | (128, 80, 80) |
| 下采样  | `down_p3(p3_td)`              | (128, 80, 80)  | (256, 40, 40) |
| PAN融合 | `fuse_p4_2(cat[down, p4_td])` | (512, 40, 40)  | (256, 40, 40) |
| 下采样  | `down_p4(p4_out)`             | (256, 40, 40)  | (512, 20, 20) |
| PAN融合 | `fuse_p5_2(cat[down, p5])`    | (1024, 20, 20) | (512, 20, 20) |

## 7. 设计要点

1. **通道数匹配**: 使用 1×1 卷积调整通道数，确保 concat 时维度一致
2. **空间尺寸匹配**: 使用 Upsample/stride=2 卷积调整空间尺寸
3. **特征融合**: 使用 3×3 卷积融合 concat 后的特征
4. **信息流动**: FPN 自顶向下传递语义，PAN 自底向上传递定位信息
5. **多尺度检测**: 三个不同尺度的输出适配不同大小的目标

这种设计使得网络能够同时利用高层语义信息和低层细节信息，显著提升多尺度目标检测性能。
